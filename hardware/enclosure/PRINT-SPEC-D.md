## 装配顺序

1. **头舱装雷达（先单独做）**
   - 雷达**天线/光敏面**贴住头舱前壳的 2.0mm 前壁；**光敏对准 6×6 窗**（窗中心在模块中段）；5P 插针端朝**内侧（靠右）**。
   - 只在模块四边贴小块泡棉双面胶，**不要盖住天线和光敏**。
   - 5P 头和线从内侧壁走线口/后盖底槽出去；把 `v8-head-back` 后盖扣上，四周点胶；**13mm 叠层不要硬压**（腔深 14mm）。
2. **头舱上框**
   - 头舱前脸下延的裙边（y42~52.45）贴在前框左上正面，点胶；后盖下壁坐在前框顶边上。
   - 雷达线从后盖下壁的出线口，经按键凹槽后封板左端的缺口，落到腔体；线走在按键条后方。
   - 头舱右边缘与最左按键帽之间有约 0.9mm 间隙；**不要粘到按键条/帽**。
3. **装板**：屏玻璃进 83.6×62.4 窗口；板边泡棉胶贴前框背面；板上边缘三个开关落在按键条下方。
4. **装按键**：三颗帽先插进按键条；按键条放进凹槽，从背面看柱尖对三个开关（±1.5mm 可调）；柱尖贴 0.5~1mm 泡棉；对正后点胶按键条两侧；**别把遮屏沿粘到屏幕上**；再把 `v8-niche-back` 粘在按键条后面（线从缺口走）。
5. **接线**：雷达 `VCC→5V(VBUS)`、`GND→GND`、`OUT→GP1`、`UART_Tx→GP2`、`UART_Rx→GP3`（2×8 排母）。
6. **侧板/后板**：左板（无孔）、右板（USB/TF 孔）粘前框背面；后板粘上，花面朝外，**两个麦克风导音孔和出音孔别堵**；顶条（63×6.5×2）平放在前框/后板顶缝上点胶；它在三个帽的后上方，**帽顶到顶条约 8mm**，按压不受影响；左端与头舱留 4mm 走线缝。
7. **插卡/线**：microSD 从右侧板 TF 槽插入；USB-C 从右侧缺口+侧板孔插入。
8. **测试**：
   - 三个键“咔哒”、回弹；最左键不被头舱挡。
   - App 看雷达有人/距离；遮/放 6×6 窗，光敏值变化；若不用光敏联动，在 HLKRadarTool 关掉“光敏联动”。
   - 语音唤醒/录音电平；后板麦孔别堵。

## 电池脱线供电改造（雷达不插 USB 也能用）

### 为什么要改

雷达 VCC 原本接的是 `5V(VBUS)`，即 USB 口进来的 5V。拔掉 USB 后该脚无电，而 ESP32、
ST7305 反射屏走电池经 3.3V 稳压照常工作 —— 现象就是「整机正常，只有雷达不亮」。板子
自带 18650 座和充电管理，本来就是为电池供电设计的，只要给雷达补一路常开 5V 即可。

**不要把雷达 VCC 直接改接 3.3V**：LD2410B-P 规格 5V，平均 70~80mA、峰值约 120mA，
厂家要求电源能力 ≥200mA；板载 3V3 是 LDO 输出，带不动，典型表现是雷达和 ESP32 一起
反复重启。

### 前提：接线是插拔的，不需要焊

雷达模块通过 1.27 插针 + 转接板接到板子背面 **2×8 排母**，全是杜邦插拔。
所以「把 VCC 那根线换一路 5V」不需要电烙铁；也不需要万用表 —— 买**固定 5V
输出**的成品（带 USB-A 母座或端子，出厂已稳压），验收看串口有没有
`radar: UART 开始出帧` 即可，比量电压还直接。

### 方案 0：零改造，今天就能用

小充电宝 + 一根 20~30cm 短 USB-C 线，藏在桌宠后面。USB 口有 5V，VBUS 就有电，
雷达 / 屏幕 / 语音全部正常，固件 0.1.65 也照常工作。

注意：不少充电宝有「小电流自动关机」（负载低于 50~100mA 就断输出），桌宠待机
5V 侧约 70~110mA，可能刚好触发。挑带**小电流模式**的（通常连按两下电源键），
或先试一晚看会不会自己断电。这仍然是接着一个电源，只是不连墙、不连电脑。

### 方案 1：真无线，免焊免表（推荐）

**物料**：一个**固定 5V 输出**的成品电源（18650 电池盒带 USB-A 输出 + 开关，
或最小的充电宝 / 5V 输出模块，输出能力 ≥200mA）、一根 USB-A 公转两根杜邦的线、
母对母杜邦线若干。不需要焊台，不需要万用表。

**接线**（全部插拔）

| 从 | 到 |
|---|---|
| 雷达 VCC 那根杜邦线 | 从排母 `VBUS/5V` 脚拔下 → 接成品 5V 正 |
| 成品 5V 负 | 板子排母上任一 `GND` 脚（**必须共地**） |
| 成品电源开关 | 手动即可；不接 GP7 也能用 |
| 雷达 OUT / TX / RX / GND | GP1 / GP2 / GP3 / GND，全部不动 |

整机仍由板上 18650 供电，雷达单独吃外置 5V；两块电池分别充电。外壳腔内放不下
就贴在外壳背面或底座下。这种接法下 GP7 悬空，固件的「低电自动关雷达」用不上
（音量上限保护仍然生效），靠成品上的开关手动断电。

**验收**（不用万用表）

1. 拔掉 USB，打开外置 5V 开关，串口 115200 应出现 `radar: UART 开始出帧`
2. 状态里 `uart=1`；问「有人吗」能返回距离；管理页不再显示「未就绪」
3. 电池电压下降后串口出现 `供电策略 → 省电 / 低电`

**可能一分钱不花的先手**：拔掉 USB 开机，看排母丝印上除 `VBUS/5V` 外有没有
第二个标着 `5V` / `VOUT` / `VSYS` 的脚。有的话把雷达 VCC 换插过去试一下，出帧
就说明板上有电池升压出来的常开 5V，直接解决。**不要往标 GPIO 号的脚上试。**

### 方案 2：从板上电池取电（焊接完整教程）

#### 0. 认清你的升压模块

不同型号丝印位置不同，一律**看板上的字**对号入座：

- `IN+ / IN-`（或 `VIN / GND`）：输入，接电池
- `OUT+ / OUT-`（或 `VOUT / GND`）：输出，接雷达
- 蓝色小电位器：**只有可调输出模块才有**
- `EN`：使能脚，可能没有。带 EN 的模块若**不接 GP7，要把 EN 短接到 IN+** 保持常开，
  别悬空（悬空往往不输出）
- 若买的是固定 5V 输出（带 USB-A 母座那种），没有电位器，跳过调压步骤

**最重要的一条**：常见的 MT3608 可调小板出厂输出往往不是 5V（有的预设 12V
甚至更高）。**必须先空载用万用表调到 5.00V 再接雷达**，否则一上电就烧雷达。

#### 1. 断电与安全（必须照做）

- 拔掉 USB、**把 18650 从座里取出来**，按几下电源键放电。18650 短路会发烫甚至起火，
  焊电池座时电池绝对不能在座里
- 烙铁 320~350℃，单点停留不超过 3 秒；先给线头和焊盘分别上锡，再对接
- 每根线套热缩管或缠电工胶布，别让裸线碰到外壳或其它焊点
- 尽量**少在主板焊**：只在电池座取电，其余都在升压模块和杜邦线端完成

#### 2. 用万用表把焊点找出来（别靠猜）

万用表：黑表笔插 `COM`，红表笔插 `VΩ`，转到直流电压档 `V⎓` 20V。
黑表笔固定接一个已知地（排母 `GND` 脚或 USB-C 金属外壳）。

装回电池、开机、**拔掉 USB**，红表笔逐个量，记录读数：

| 量到的点 | 拔 USB 时读数 | 结论 |
|---|---|---|
| 原 `VBUS/5V` 脚 | **0V**（插上 USB 约 5V） | 确认了诊断，就是要绕开它 |
| `3V3` 脚 | 3.3V 常开 | **不要**用它给雷达 |
| 电池正极 `BAT+` | **3.0~4.2V 常开** | 焊点 ① 的取电点 |
| 任一 `GND` | 0V；蜂鸣档应响 | 焊点 ② / ④ |

排母上找不到标 `BAT+` 的脚也没关系：**直接用 18650 电池座的正极弹片**，这是最
可靠的取电点，负极弹片同理。用蜂鸣档确认「电池座负极弹片 ↔ 排母 GND」是通的。

#### 3. 只焊 4 个位置（+1 个可选）

| 编号 | 从 | 到 | 说明 |
|---|---|---|---|
| ① | 电池座**正极弹片**（或找到的 `BAT+` 焊盘） | 升压模块 `IN+` | 红线，焊时电池必须取出 |
| ② | 电池座**负极弹片**（或 `GND`） | 升压模块 `IN-` | 黑线 |
| ③ | 升压模块 `OUT+` | **雷达 VCC 那根杜邦线** | 把 VCC 从排母 `VBUS` 脚拔下，改接 `OUT+`；杜邦端能插就不必焊 |
| ④ | 升压模块 `OUT-` | 排母任一 `GND` 脚 | **必须共地**，不共地 UART 不会出帧 |
| ⑤ 可选 | 升压模块 `EN` | `GP7` | 没有 EN 就忽略；不接 GP7 则把 EN 短接 `IN+` |

`雷达 OUT / TX / RX / GND` 四根线接 `GP1 / GP2 / GP3 / GND`，**全部保持不动**。
所以真正落在主板上的焊接只有 ①② 两处（而且都在电池座弹片上，不在芯片附近）。

#### 4. 空载调压（有表了，这步别跳）

1. 只接好 ①②，`OUT` 端**什么都不接**，雷达先别接
2. 装上电池，万用表量 `OUT+` 对 `OUT-`
3. 可调模块：慢慢转电位器，调到 **5.00V**（4.90~5.10V 可接受，**绝不要 >5.2V**）。
   转很多圈读数不动，可能是方向转反了，或你买的是固定输出款
4. 固定输出款：直接确认读数在 4.9~5.1V
5. **断电**，再往下接

#### 5. 接雷达与共地检查

断电状态下接 ③④（和⑤），然后：

- 蜂鸣档：`OUT-` ↔ 板子 `GND` ↔ 雷达 `GND` 三处应互通
- 电压档：`OUT+` 对 `GND` = 5.0V；`OUT+` 对 `3V3` **不短路**
- 确认 `VCC` 那根线已经**不在** `VBUS` 脚上了

#### 6. 上电验收

1. 拔掉 USB，串口 115200 出现 `radar: UART 开始出帧`
2. 量雷达 `VCC` 对 `GND` = 5.0V（不是 0V）
3. 状态里 `uart=1`；问「有人吗」能返回距离，管理页不再显示「未就绪」
4. 插回 USB 充电也正常；电池电压下降后串口出现 `供电策略 → 省电 / 低电`

#### 7. 排错

| 现象 | 最可能的原因 | 怎么查 |
|---|---|---|
| 模块发烫 / 无输出 | `IN+ / IN-` 接反，或输出短路 | 立刻断电，蜂鸣档查 `OUT+` 对 `GND` |
| 输出只有 3~4V | 电位器没调到位，或电池快没电 | 空载重调；量 `IN+` 是否 ≥3.0V |
| `VCC` 有 5V 但不出帧 | 没共地，或 TX/RX 被碰松 | 蜂鸣档查共地，重插三根信号线 |
| 板子反复重启 | 5V 串进了 3V3，或电池被拉垮 | 断电，量 `3V3` 是否被抬到 5V |
| 带 EN 但一直没输出 | EN 悬空 | EN 短接 `IN+`，或按 ⑤ 接 GP7 |

#### 8. 长期注意

升压模块静态电流约 1~2mA，一直挂在电池上，长期不用的话会把 18650 慢慢放到
过放（约 1~2 个月）。要么在 ① 上串一个物理小开关，要么长期收纳时把电池取出来。
接了 EN 的话，固件在电池 <3.35V 时会自动关掉雷达，但模块本身的静态电流仍在。

### 功耗与固件配合

雷达常开约 0.35W，升压静态电流 1~2mA，整机约 0.8~1W，18650 约 9~12 小时。
固件 `main.c` 的 `power_tick()` 会按电池电压分级：

| 电压 | 策略 |
|---|---|
| ≥3.70V | 正常，音量不限制，雷达常开 |
| <3.70V | 省电：音量上限压到 75（躲开功放电流尖峰） |
| <3.35V | 低电保命：音量上限 50，通过 EN 关掉雷达，屏幕提示充电 |

各级带回差（回升 80mV 才解除），避免电压抖动来回切。低电时关雷达是为了保住
ESP32 和屏幕；接上 USB 充电、电压回升后自动恢复。

**如果 GP7 不能用**：改 `firmware/components/radar/include/radar.h` 的
`RADAR_PWR_GPIO` 到任意空闲 GPIO 并重编固件。完全不接 EN 线也能正常使用，
只是失去软件开关和低电自动断电。
